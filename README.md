# Debie Galleros — Data Pipelines & Dashboards

Data analytics, data engineering and data visualization portfolio, live at **https://debiegalleros.github.io/pipelines-and-dashboards**.

## What's on the page

- How the data flows: sources, extract and transform, storage, dashboards
- Nine case studies, from AWS and Snowflake pipelines to GA4 tracking and community analysis
- Twelve dashboard recreations in three industries: pharma, infant nutrition and banking
- A sample quarterly report deck
- GA4 event tracking and custom dimensions
- SQL and Python examples

## Files

- `index.html` — the portfolio page
- `Debie-Galleros-Data-Pipelines-and-Dashboards.pdf` — the same content as a PDF

Client, brand and colleague names and all business figures are left out. The dashboards and the deck use sample data, and the code examples are rewritten, not copied from any employer.
